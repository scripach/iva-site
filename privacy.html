Политика конфиденциальности

Дата последнего обновления: 11 октября 2026 г.

Приложение Iva — личный ассистент, работающий на персональном сервере владельца. Эта политика описывает, какие данные приложение получает через Google API, как их использует и как защищает.

1. Какие данные мы получаем

После того как владелец авторизует приложение, оно получает доступ к данным своего же Google-аккаунта:

  • адрес электронной почты и базовый профиль;
  • письма Gmail — для поиска важных сообщений и подготовки сводок;
  • события Google Календаря — для планирования дня и напоминаний;
  • задачи и другие сервисы Google (Таблицы, Документы) — по мере необходимости для работы ассистента.

2. Как используются данные

Данные используются исключительно для того, чтобы ассистент выполнял поручения владельца: показывал новые письма, напоминал о встречах, готовил обзоры дня. Автоматическая рассылка, реклама и профилирование не применяются.

3. Хранение и защита

Данные обрабатываются и хранятся на персональном сервере владельца. Доступ к серверу ограничен владельцем; передача данных идёт по защищённым каналам (HTTPS).

4. Передача третьим лицам

Данные не продаются и не передаются третьим лицам. Передача возможна только по законному требованию уполномоченных органов.

5. Ограничение использования Google-данных

Приложение использует полученные данные только в объёме, необходимом для работы ассистента, и не передаёт их сторонним приложениям. Использование данных соответствует Политике использования данных пользователей сервисов Google API, включая требования ограниченного использования (Limited Use).

6. Удаление данных

Владелец может в любой момент отозвать доступ приложения к аккаунту на странице Сторонние приложения с доступом к аккаунту. Для удаления сохранённых данных достаточно написать на scripachd@gmail.com — данные будут удалены.

7. Контакты
