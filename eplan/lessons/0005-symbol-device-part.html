Урок 05 · первый символ

Символ, устройство, изделие

Три разные сущности, которые новичок принимает за одну. Поймёте разницу — навигатор устройств перестанет быть пустым, а отчёты обретут данные.

≈ 25 минут нужен лист &С3 из урока 4 ключ ко всем отчётам

Из справки: символ содержит графику, точки вывода устройства и логику, то есть определение функции. Именно определение функции, а не картинка, делает символ автоматом, а не просто квадратиком.

Термины «определение функции», «вывод устройства», «изделие» — в глоссарии. Какие формы понадобятся дальше — в справочнике по шаблонам.

Символы нужны, чтобы начертить схему соединений простым способом. Они обладают большим количеством информации, такой как графические элементы, точки вывода устройства, присвоение к группе символов, логика.

EPLAN Help 2025, «Символы»

Откуда берётся обозначение -Q1

Когда вы ставите символ, EPLAN сразу создаёт устройство. Обозначение подставляется автоматически по правилам нумерации проекта — по буквенному коду определения функции: Q для автоматов, K для реле, X для клеммников.

Поэтому навигатор устройств наполняется сам, как только вы поставите первый символ. Если он пуст — значит символов на логических страницах нет.

Почему это важно

Отчёты — перечень элементов, спецификация, кабельный журнал — строятся по устройствам, а не по графике. Нет устройств — нет строк в отчёте. Это и есть механизм «пустой отчёт», с которым вы столкнётесь в следующем уроке.

Практика: поставить символ

  1. Откройте лист &С3, созданный в уроке 4.
  2. Откройте центр вставки: Главная › Символы (строка навигации центра вставки).
  3. Выберите библиотеку символов и найдите простой символ с выводами — например замыкающий контакт.
  4. Поставьте его на лист. EPLAN присвоит устройству обозначение автоматически.
  5. Откройте навигатор устройств. Устройство появилось — с обозначением вида -K1 или -Q1.
Если EPLAN ругается при вставке

Из справки: выводы устройства, направленные в одну сторону, не могут находиться друг над другом. При попытке такого размещения выводится сообщение об ошибке и вставка прерывается. Исключение — символы с выводами в противоположных направлениях, например тройник.

Практический вывод: разносите символы по горизонтали, не ставьте один строго над другим.

Практика: присвоить изделие

Пока у устройства нет изделия, в отчёте будет пустая графа «Наименование». Присвоение — отдельное действие.

  1. Дважды щёлкните по условному обозначению на листе — откроется диалог «Свойства».
  2. Перейдите на вкладку «Изделие».
  3. Нажмите кнопку выбора изделия — откроется диалог, где можно найти позицию в базе.
  4. Выберите изделие и подтвердите. Устройство получило каталожные данные.

Условие: Вы открыли диалоговое окно Свойства <...> для главной функции и выбрали вкладку Изделие.

EPLAN Help 2025, «Выбрать изделие»

Выбор изделия вызывается и из других мест — из навигатора устройств, навигатора спецификаций или списка устройств. Для первого раза проще через свойства символа.

При помощи выбора изделия устройству присваивается одно или несколько изделий. При многократном выборе изделий возможно одновременное присвоение нескольких изделий. При этом функции / условному обозначению присваиваются данные первого изделия, содержащегося в выборе.

EPLAN Help 2025, «Выбрать изделие»

Изделия можно присваивать какой-либо функции при помощи выбора изделия или устройства. Выбор изделия позволяет выполнять выбор изделия на основе коммерческих данных, выбор устройства осуществляется на основе технических признаков.

EPLAN Help 2025, «Выбор изделия / устройства»

Разница простая: выбор изделия — по артикулу и цене, выбор устройства — по техническим параметрам (напряжение, число контактов, габариты). Для подбора реле по току удобнее второе.

Одному устройству — до 50 изделий

Реле в проекте — это одно устройство, но закупать нужно само реле, колодку под него и фиксатор на DIN-рейку. Всё это присваивается одному устройству как несколько изделий. Так и получается корректная спецификация.

Проверить результат

  • В навигаторе устройств есть хотя бы одна строка с обозначением.
  • У устройства видно присвоенное изделие — артикул и наименование.
  • На листе символ выглядит как обычно, но под ним теперь стоят данные.

Где это в комплекте

Устройства и присвоенные изделия — источник данных для перечня элементов и спецификации. Сколько листов занимают эти документы в реальном проекте — в справочнике по составу АСУ ТП.

Итог урока

Что должно остаться в голове
  • Символ — графика, устройство — логика, изделие — каталог. Три разных уровня.
  • Обозначение появляется само при вставке символа, по буквенному коду функции.
  • Навигатор устройств заполняется сам — пустой список означает отсутствие символов.
  • Изделие присваивается отдельно, и без него отчёт будет с пустыми графами.
