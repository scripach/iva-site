Урок 04 · создание документа

Завести схему автоматизации с нуля

Схемы автоматизации в шаблоне СПДС отсутствуют — документ &С3 придётся завести. Вы создадите его, положите первый лист и проверите, что он встал в нужный раздел структуры.

≈ 20 минут шаблон СПДС открыт один лист за урок

В шаблоне СПДС есть общие данные (&ОД) и описание систем классификации (&П7, 5 листов). Документа &С3 среди них нет.

Так и должно быть: шаблон задаёт каркас комплекта, а схемы автоматизации — ваша работа. Заводить их придётся вручную, но один раз понять порядок — дальше пойдёт быстро.

Что такое код вида документа

В структуре проекта есть отдельный блок идентификаторов — Вид документа. По справке у него предшествующий знак — пробел или &:

Вид документа — предшествующий знак: Пробел, &.

EPLAN Help 2025, «Определить пользовательскую структуру проекта»

В шаблоне КБ-625 выбран знак &, поэтому все документы выглядят как &С3, &ОД, &П7. Сам код после знака — это шифр документа по ГОСТ 34.201 и СПДС. Именно по нему EPLAN собирает содержание альбома и ведомость документов.

Коды из комплекта АСУ ТП

&С3 — схемы автоматизации. &СБ — принципиальные. &С4 — таблица соединений. &Э5 — подключение блоков управления. Полный разбор с объёмами — в справочнике по составу АСУ ТП.

Тип страницы: почему это важно

Кроме кода документа у каждой страницы есть тип. И здесь есть тонкость, которая определяет, будет ли EPLAN строить соединения. Определения «вид документа», «полное имя страницы», «тип страницы» — в глоссарии.

На логических страницах выполняется оценка и анализ данных устройств и автоматически генерируются линии автоматических соединений. (Исключение: на страницах типа «Компоновка электрошкафа», «Обзор» и «Предварительное планирование» нет автоматического соединения). Такие операции не выполняются на графических страницах, они используются для отображения данных или для черчения графики.

EPLAN Help 2025, «Типы страниц»

Для схемы автоматизации нужен тип страницы схемы соединений — тот, на котором EPLAN строит автоматические соединения. Ориентир по названию в списке: «Многопол. схема соедин.».

Рядом с названием типа в списке стоит буква в скобках. Она не заменяет критерий, а только помогает отсеять лишнее:

Что означает буква рядом с типом страницы
БукваСмысл по справкеГодится для схемы?
(A) Автоматическая — страница генерируется и заполняется программой как отчёт (например, «Спецификация изделий») Нет
(I) Интерактивная — создаётся и обрабатывается пользователем. Сюда входят и страницы схемы соединений, и графические страницы Не любая — графическая автосоединение не строит

Отсюда практическое правило: сначала смотрите на название, а буква (I) лишь говорит, что страницу делаете вы, а не программа. Среди (I) есть графические страницы для черчения — они соединений не строят.

Проверка после создания

Если на листе не появляются линии автоматического соединения при постановке символов — первым делом проверьте тип страницы. Графический тип соединений не строит, и это самая частая причина «EPLAN не видит мои провода».

Практика: создать документ &С3

Шаг 1. Открыть диалог создания

  1. Откройте навигатор страниц: F12.
  2. Выберите Главная › группа команд «Страница» › Создать.
  3. Откроется диалог «Новая страница».

Если в навигаторе был выделен какой-то лист, EPLAN подставит его свойства в диалог. Нажмите кнопку «Очистить поля», чтобы начать с чистого листа — иначе унаследуете код &П7 вместо нужного.

Щелкните по кнопке [Очистить поля], если необходимо очистить поля данных текущей выделенной страницы, то есть удалить их содержимое. Содержимое полей данных удаляется. Только «тип страницы» занят типом выделенной страницы. Кроме того, остается автоматически назначенное имя страницы.

EPLAN Help 2025, «Создать и удалить страницы»

Шаг 2. Задать полное имя страницы

В поле «Полное имя страницы» нажмите кнопку [...] — откроется диалог, где структурные идентификаторы задаются по отдельным полям. Так надёжнее, чем вписывать строку вручную: EPLAN сам расставит разделители.

Заполните:

  • Вид документа — С3. Это и создаст узел схем автоматизации.
  • Номер страницы — 1.
  • Остальные блоки (функциональное присвоение, место установки) — оставьте как есть или заполните по своему объекту.
Куда попадёт документ

Если оставить структуру без изменений, лист встанет в тот же раздел дерева, где лежит &П7 — в «Прилагаемые документы → Документы на АС → Информационное обеспечение». Для схем автоматизации это не то место: они относятся к основному комплекту рабочих чертежей.

Поэтому на уровне выше выберите раздел «Основной комплект рабочих чертежей». Разбор того, почему в дереве две оси группировки, — в справочнике по составу АСУ ТП.

Шаг 3. Выбрать тип страницы

В поле «Тип страницы» откройте список и выберите тип с названием «Многопол. схема соедин.». Буква (I) рядом подтвердит, что это интерактивная страница, а не отчёт.

Шаг 4. Заполнить описание

В поле «Описание страницы» впишите понятный текст, например: «Схема автоматизации. Узел 1». Это описание появится в дереве навигатора и в отчётах.

Для каждой страницы можно ввести описание, например, «Силовая электрическая цепь, насос 1» или «Управляющая электрическая цепь, транспортер 3».

EPLAN Help 2025, «Свойства страницы»

Шаг 5. Подтвердить и проверить

  1. Нажмите [OK]. Лист создан и открыт в редакторе.
  2. Разверните дерево навигатора. Появился узел &С3 с листом 1 — в том разделе, который вы выбрали.
  3. Посмотрите на вкладку над чертежом: там полное имя страницы.
  4. Проверьте рамку и основную надпись — они подставились из формы шаблона.

Дальше: нарастить документ

Один лист — это ещё не схема на весь объект. Второй лист делается быстрее первого:

  1. Выделите созданный лист в навигаторе одним щелчком.
  2. Главная › Страница › Создать.
  3. Поля уже заполнены — код &С3 и тип сохранились. Измените только номер страницы на 2.
  4. [OK].

Так же набирается весь документ на 10–20 листов: один раз настроили — дальше меняете номер.

Готовые формы под схемы автоматизации

В шаблоне есть формы именно для &С3 — по два листа (первый и следующий) для семи вариантов перечней. Их имена: СПДС_С3_пк_1с, СПДС_С3_пк_сл, СПДС_С3_пкп_*, СПДС_С3_пкт_*, СПДС_С3_поа_*, СПДС_С3_пвс_*, СПДС_С3_пвщ_*, СПДС_С3_птр_*. Выбор варианта зависит от того, какие перечни нужны на подвале листа. Полный список форм — в справочнике по шаблонам.

Посмотреть, как это делают другие

  • Создание страниц. Нумерация страниц Александр Павлов Тот же диалог «Создать страницу», но с акцентом на нумерацию: как номер листа привязывается к документу.
  • Eplan electric. Свойства общие Александр Павлов Свойства как источник данных для отчётов: где лежат поля, из которых потом собирается спецификация.
  • Eplan electric. Режимы копирования Александр Павлов Быстрый способ нарастить документ до 20 листов, когда копируете не страницу, а её содержимое.

Итог урока

Что должно остаться в голове
  • Код &С3 создаёт документ. До появления первого листа такого узла в дереве нет.
  • Тип страницы решает, будут ли соединения. Нужен «Многопол. схема соедин.». Буква (I) сама по себе ничего не гарантирует.
  • «Очистить поля» — когда создаёте от выделенного листа другого документа.
  • Второй лист делается копированием свойств первого.
