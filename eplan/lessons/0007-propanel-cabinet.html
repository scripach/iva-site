Урок 07 · шкаф

Компоновка шкафа в Pro Panel

Схема отвечает на вопрос «что с чем соединено». Компоновка — на вопрос «где это физически стоит». Из неё получаются чертёж общего вида и сверловка монтажной платы, без которых шкаф не изготовить.

≈ 25 минут модуль Pro Panel в установке есть основа для чертежей шкафа

Зачем это АСУ ТП-шнику

Комплект документации на шкаф не ограничивается схемами. В реальном проекте, разобранном в справочнике по составу, есть отдельные документы:

Это и есть выход Pro Panel: 13 листов чертежа общего вида руками не рисуют — их получают из 3D-компоновки.

Как устроена компоновка

В Pro Panel шкаф — это трёхмерный объект с монтажными поверхностями. Порядок работы такой:

  1. Завести шкаф. Корпус с габаритами: ширина, высота, глубина.
  2. Добавить монтажные поверхности. Монтажная плата, боковые стенки, дверца.
  3. Поставить DIN-рейки. На них крепятся аппараты.
  4. Разместить устройства. Те самые, что уже есть в проекте после урока 5.
  5. Получить чертежи. Общий вид, сверловка, легенды.
Ключевое преимущество

Устройства не расставляются заново — берутся из проекта. Один и тот же автомат -Q1 существует и на схеме, и в шкафу. Изменили схему — изменилась компоновка. Это и есть сквозное проектирование, ради которого внедряют EPLAN.

Габариты: где их брать

Чтобы аппарат занял правильное место, у изделия в базе должны быть заданы монтажные данные — ширина, высота, глубина. Без них 3D-компоновка не построится.

Данные приходят из двух источников: из базы изделий (если вы скачали позицию с портала EPLAN) или задаются вручную в свойствах изделия. Для отечественного оборудования второе — обычная практика.

Ориентация осей

В базе изделий габариты задаются с учётом того, что монтажная поверхность повёрнута на −90° по оси Y. На практике это значит: ширина — по оси X, высота — по оси Z, глубина — по оси Y. Если перепутать, аппарат ляжет на бок в 3D.

Практика: первый шкаф

Шаг 1. Завести корпус

  1. Откройте проект, в котором уже есть устройства (после урока 5).
  2. Создайте страницу типа «Компоновка электрошкафа» — это графический тип, автосоединений на нём нет и не нужно.
  3. Вставьте шкаф из базы изделий: найдите позицию с типом «корпус шкафа».
  4. Задайте габариты, если они не пришли из базы.

Шаг 2. Добавить монтажную плату

  1. Вставьте монтажную плату внутрь корпуса.
  2. Проверьте, что она встала на нужную глубину, а не вплотную к дверце.

Шаг 3. Поставить DIN-рейку

Рейка — тоже изделие из базы. Если стандартной длины не хватает, рейку можно создать нестандартной: в уроках ниже показано, как это делается и как задать шаг сетки под конкретные аппараты.

Шаг 4. Расставить аппараты

  1. Откройте навигатор устройств.
  2. Перетащите устройства на монтажную плату.
  3. EPLAN расставит их по рейке с учётом габаритов.
  4. Проверьте, что ничего не пересекается и не выходит за габариты.

Шаг 5. Получить чертёж

Из компоновки генерируются отчёты — те же команды, что и для схем: Инструменты › группа команд «Отчёты» › Генерация отчёта по проекту. Чертёж общего вида и сверловка встают в документы -Н и -ДИ.

Итог урока

Что должно остаться в голове
  • Компоновка — не рисование, а расстановка готовых устройств из проекта.
  • Габариты изделий — основа 3D. Нет монтажных данных — нет компоновки.
  • Чертёж общего вида получается отчётом, а не рисуется руками.
  • Тип страницы «Компоновка электрошкафа» — графический, автосоединений на нём нет.
  • Рейка — изделие с монтажными данными: без них её не поставить в шкаф.
