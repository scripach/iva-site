Глоссарий EPLAN × АСУ ТП

Единая терминология курса. Если урок расходится с этим файлом — прав файл. Русские названия команд — из официальной справки EPLAN (портал eplan.help/ru-ru) и локализации 2025.

Ядро EPLAN

Проект (Projekt) — один файл *.elk (либо папка *.elk + сопутствующие), содержащий все страницы, устройства, отчёты и внутренние базы данных. Единица работы. Расширение резервной копии — *.zw1.

Базовый проект (Basisprojekt) — проект-заготовка, от которого «наследуется» новый проект: структура обозначений, рамки, формы, настройки отчётов, слои. В EPLAN 2025 штатно поставляются GOST_bas001.zw9, IEC_bas001.zw9, NFPA_mm_bas001.zw9, EPLAN_Tutorial.zw9 в папке Templates\EPLAN внутри установки EPLAN.

Страница (Seite) — лист проекта. Имеет имя из структурных идентификаторов, например =A1+B2&С3/12. Не бывает проекта без страниц.

Навигатор страниц — дерево всех страниц проекта, основной способ навигации. Открывается и закрывается клавишей F12.

Обозначения и структура

ОУ (обозначение устройства, BMK) — уникальное имя устройства в проекте. Собирается из блоков структурных идентификаторов.

Structural identifier / структурный идентификатор — блок ОУ с предшествующим знаком:

Знак Аспект Смысл Пример
= функция чему принадлежит =A1 — установка A1
+ место где физически стоит +B2 — шкаф B2
- продукт что это за изделие -K3 — реле K3
& документ вид документа страницы &С3 — схема автоматизации

Читается =A1+B2-K3 как: «реле K3, в шкафу B2, установки A1».

Схема идентификаторов (Kennzeichen-Schema) — шаблон, задающий, из каких блоков строится ОУ и страницы.

Меняется через Файл › Сведения › группа команд «Свойства проекта» › Структура. Эта команда появляется только когда проект открыт и выделен в навигаторе страниц — то есть сначала F12, выделить проект, потом меню. В пустом EPLAN, без открытого проекта, в разделе «Сведения» будут лишь «Создать», «Открыть», «Резервировать» и прочее управление файлами.

Второй путь, тоже проверенный: в навигаторе страниц выделить проект → правая кнопка → Свойства → в открывшемся окне «Сведения» выбрать Структура.

Третий путь, если проект не хочется открывать: Файл › Управление проектами → выделить проект → вкладка Структура.

Что можно менять в готовом проекте (по справке, «Структура проекта: Основные положения»):

  • расширять структуру страниц — всегда можно (добавить блок идентификаторов или сменить статус с «Описывающего» на «Идентифицирующий»);
  • сужать — только если при этом не появятся двойные страницы;
  • при появлении дублей страниц изменение блокируется.

Позиционное обозначение — буквенно-цифровой код по ГОСТ 2.710: Q1 (автомат), K3 (реле), M1 (двигатель), X1 (клеммник), A1 (устройство/блок), T1 (трансформатор), R5, C2, SB1 (кнопка), HL1 (лампа), U1 (преобразователь).

Полное ОУ — ОУ вместе со всеми структурными идентификаторами: =A1+B2-K3.

Устройства и изделия

Устройство (Betriebsmittel) — набор функциональных элементов, объединённых одним ОУ. Логическая сущность проекта; существует только в проекте.

Изделие (Artikel) — запись в базе данных изделий: каталожный номер, производитель, цена, размеры, макросы. Физическая сущность из каталога.

Взаимосвязь: изделие — шаблон; устройство — его копия в проекте со своими локальными свойствами. Одному устройству можно присвоить до 50 изделий (например, реле + колодка + фиксатор). Удаление устройства уничтожает копии, но не шаблон.

База данных изделий системы — внешняя (SQL Server / Access), общая для всех проектов. В EPLAN 2025 — SQL Server 2022 Express.

База данных изделий проекта — внутренняя, хранится в самом .elk. Работа с изделием внутри проекта идёт только через неё.

Список устройств — предварительный перечень изделий, из которых должен состоять проект; импортируется/экспортируется в Excel.

Определение функции (Funktionsdefinition) — «математическая модель» элемента: какие выводы, какие свойства, какое УГО. Именно определение функции, а не картинка, делает символ автоматом или реле.

Символ — графика функционального элемента. Один символ + разные определения функции = разные устройства.

Схемы и связи

Автосоединение (Autoconnecting) — механизм, при котором EPLAN сам строит электрические соединения по геометрии нарисованных линий. Основа всей автоматизации; без него нет ни таблицы соединений, ни проверки.

Точка соединения / точка разрыва (T-Verbindung) — место ветвления, где автосоединение создаёт связь.

Потенциал (Potenzial) — электрически общая цепь (например, L1, N, PE, 24V). Управляет цветом и логикой соединений.

Перекрёстная ссылка (Querverweis) — автоматическая ссылка между частями одного устройства на разных листах: → 12.4 (страница/строка).

Экран/ЭМС — экран кабеля как отдельное устройство с функцией «экран».

Документы и отчёты

Отчёт (Auswertung) — генерируемый из проекта документ: перечень элементов, таблица соединений, кабельный журнал, спецификация.

Перечень элементов (Betriebsmittelliste) — список всех устройств с позициями, наименованиями, количеством. По ГОСТ 2.701 — обязательный документ к схеме.

Таблица соединений — таблица «откуда → куда» для каждого проводника. По ГОСТ 2.413-72 может выпускаться как самостоятельный документ.

Спецификация оборудования, изделий и материалов — по ГОСТ 21.110-2013, строительная часть. Не путать с перечнем элементов (ЕСКД).

Форма (Form) — шаблон оформления отчёта: какие колонки, какая основная надпись. Файлы *.fn1.

Рамка (Rahmen) — шаблон листа: рамка + основная надпись. Файлы *.fn1 того же типа.

Основная надпись (штамп) — по ГОСТ 2.104 / ГОСТ Р 21.1101. В EPLAN — часть формы/рамки с автоматическими свойствами проекта.

Pro Panel и шкаф

Pro Panel — модуль 3D-компоновки шкафа. Присутствует в установке (SystemProPanelu.erx).

Монтажная плата (Montageplatte) — плоскость внутри шкафа, на которой размещают аппараты.

Монтажное пространство (Montagerraum) — 3D-объём шкафа в Pro Panel.

DIN-рейка (Tragschiene) — профиль для крепления аппаратов; в базе изделий задаётся как монтажный аксессуар.

Ш×В×Г — габариты изделия в базе (ширина × высота × глубина). Задаются с учётом поворота монтажной поверхности на −90° по оси Y — частая причина ошибок в 3D.

Чертёж сверления (Bohrbild) — автоматически получаемый чертёж отверстий монтажной платы.
