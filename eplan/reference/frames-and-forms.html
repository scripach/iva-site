Комплект шаблонов КБ-625

Что лежит в папке kb625/ рядом с уроками и что означает каждая буква в имени файла. Держите под рукой, когда настраиваете проект.

Где что лежит

Комплект лежит в папке курса, в подкаталоге kb625/ — рядом с файлами уроков. Скачивать ничего не нужно: если вы читаете этот курс, значит комплект уже рядом.

kb625/
├─ от автора.docx             ← прочитать первым, 1 страница
└─ КБ-625/
   ├─ 1_настройка/            ← документация по устройству шаблонов
   │  ├─ Eplan.docx                    572 абзаца: устройства, изделия, клеммы,
   │  │                                кабели, шины, Pro Panel, Preplanning
   │  ├─ Обозначения документов.xlsx   ← структура кодов, все поля
   │  ├─ Данные в EPLAN_ЕСКД.xlsx
   │  ├─ Данные в EPLAN_СПДС_34.xlsx
   │  └─ Preplannig.xlsx
   └─ 2_проект/
      ├─ шаблон/
      │  ├─ ЕСКД_2023.05.20_0.06.zw1     ← шаблон для конструкторских документов
      │  ├─ СПДС_2023.05.20_0.06.zw1     ← шаблон для строительных (основной для АСУ ТП)
      │  └─ ГОСТ 34_2023.05.20_0.06.zw1  ← шаблон для документов АС
      ├─ пример/
      │  ├─ АТМ_2023.05.20_0.00.zw1      ← живой проект, 69 МБ
      │  └─ КБ625.ИПС.001.23-АТМ.pdf     ← тот же проект в PDF, 258 листов
      └─ макросы/
         └─ КБ625_macros_2023.05.10_18.31.zw1

Общий объём — около 228 МБ. Это нормально: внутри проекты EPLAN, которые сами по себе весят десятки мегабайт.

Комплект распространяется автором свободно — он прямо пишет, что выкладывает наработки «для свободного пользования» и предлагает брать их за основу в своих проектах. Поэтому мы можем публиковать его вместе с курсом.

Какой шаблон когда брать

Шаблон Стандарт Когда использовать
СПДС_...zw1 ГОСТ 21.101, ГОСТ 21.408, ГОСТ 21.110 АСУ ТП по умолчанию. Рабочая документация, марка АТХ/АТМ: общие данные, схемы, чертежи, спецификации
ЕСКД_...zw1 ГОСТ 2.ххх Конструкторские документы на изделие: сборочный чертёж шкафа, спецификация по 2.106, таблица соединений по 2.413
ГОСТ 34_...zw1 ГОСТ 34.201 Документы автоматизированной системы: описание, руководство, формуляр

Один проект АСУ ТП обычно использует СПДС как основной, а ЕСКД — для шкафа как изделия.

Расшифровка имён файлов рамок и форм

Соглашение автора (из файлов ЕСКД_сокращения.txt и СПДС_сокращения.txt):

Фрагмент Значение
_1с первый лист документа (с основной надписью по форме 2)
_сл следующий лист (форма 2а)
-Д основная надпись вдоль длинной стороны листа
_титул титульный лист
_ф2, _ф2а форма 2 / форма 2а по ГОСТ 2.104
сх форма для чертежей и схем
У лист с утверждающей подписью (ГИП и т.д.)
смеж рамка для смежных основных комплектов (для ведомости комплектов)
ПД рамка для прилагаемых документов (без самого документа, напр. пояснительная записка)
чужие для документов сторонних организаций — меняются данные разработчика

Сгруппированы по назначению:

Практический вывод: прежде чем рисовать вручную хоть одну рамку или таблицу — посмотрите, есть ли готовая форма в шаблоне. С вероятностью 94/94 — есть.

Рамки по ГОСТ в стандартной поставке EPLAN

Если комплект КБ-625 почему-то недоступен, в самой EPLAN есть штатный базовый проект по ГОСТ. Он лежит в папке шаблонов вашей установки: откройте её через Файл › Настройки или найдите каталог Templates\EPLAN внутри установочной папки EPLAN. Файл называется GOST_bas001.zw9.

Его описание внутри самого файла: «Базовый проект со структурой обозначений согласно ГОСТу». Внутри 15 готовых форм: gost_a4_title_page, gost_first_page_scheme_a3, gost_a3_first_page_text, gost_specification_a4_dyn, gost_devicelist_a4, gost_cable_overview_, gost_wire, gost_table_of_contents_a4 и их «следующие страницы».

Это более простая база, чем КБ-625, но полностью официальная и без риска. Хороша как запасной вариант и как эталон правильности.

Шрифт

В комплекте есть mipgost.ttf — автор подобрал его специально: близок к ГОСТ и, в отличие от GOST type A, корректно выводит спецсимволы в отчётах EPLAN. Устанавливается в Windows обычным двойным кликом. После установки выбирается в шаблоне как основной.

Что ещё есть в полном архиве автора

Полный архив содержит также папку с «ядром» установки — базы данных, 32 437 макросов, 1122 символа, 536 форм, 357 схем, 164 рамки (включая ЕСКД_* и СПДС_*), 1396 проектов. Она копируется в общую папку данных EPLAN и подключается как источник основных данных.

Для курса эта часть не нужна: все необходимые формы уже внутри трёх шаблонов проекта. К ней стоит обращаться позже, когда понадобится расширить базу символов или изделий.
